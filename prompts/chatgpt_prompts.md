# Lista de Prompts
## Descrição
Prompt para ranquear site com mais vendas 
> Com base na planilha enviada, retorne em forma de tabela um rank dos sites tendo como base a quantidade de produtos vendidos. A tabela deverá conter as colunas: rank, site, quantidade_de_vendas.

## Descrição
Prompt para ranquear preferência de site por país 
> Com base na planilha enviada, retorne em forma de tabela um rank dos sites preferidos para compras, classificando por país de origem do pedido de compra (delivery_country). A tabela deverá conter as colunas: rank, site, quantidade_de_vendas, país_origem.
